# Tragedy Looper 本地助手（FS + BTX 模組）

本項目位於 `D:\Rooper\game`，是一個純前端的悲劇輪迴（Tragedy Looper）桌遊助手，包含以下部分：

## 0. 預設劇本選擇頁（presets.html）

- 首頁移除「開始遊戲」示例按鈕，改為進入**選擇預設**頁
- 列出全部官方預設劇本（FS 2 + BTX 9），支援搜尋與模組篩選
- 每個劇本有兩個按鈕：
  - **開始遊戲**：彈出三種模式（本地熱座 / AI 對戰 / 以此開房）
  - **查看詳情**：進入劇本編輯器並載入該預設

## 1. 劇本編輯器（editor.html）

可視化製作符合規則的劇本：

- 選擇模組：**FS 模組（第一步）** 或 **BTX 模組（基礎悲劇）**
- 選擇主規則（規則Y）與副規則（規則X，FS 可多選、BTX 2 條）
- **開啟即空劇本**：不再自動載入預設；右上角「📥 導入預設」可從 11 套官方劇本中選擇載入
- **角色池側邊欄**：可一鍵收起/展開（類似 DeepSeek 對話的拉出邏輯），為中間盤面騰出空間
- 支援 **MC / MZ / WM 模組**（模組紙已建入規則/身份/事件資料；Ex槽等部分特殊機制尚未完整實作，會在模組備註標明）
- **角色池**：`Assets/chara_live` 的 **全部 37 名角色**，卡片放大顯示，可點選查看詳情、拖曳加入劇本、一鍵移出
- **開始盤面預覽**：2×2 地圖即時顯示所有角色的初始區域（立繪用 `chara_stand`），拖曳角色到版圖即可設定/變更初始區域
- **角色詳情側邊欄**：放大卡面、不安限度、屬性、友好能力說明；點擊地圖上的角色或角色池卡片即可彈出編輯面板（身份、初始區域）
- 預定事件（日期＋事件＋效果＋當事人），每名當事人自動去重
- **模組紙 / 規則參考**：內建結構化速查（規則Y/X、身份、事件、角色卡、行動牌，可搜尋）；分頁與標題不再帶「（…）」括號，原版 PDF 與公開/非公開信息表按鈕已移除
- 即時驗證（身份數量、當事人不重複、日期範圍、屬性約束等）；**身份上限合計**（傳謠人最多1名、親友最多2名）：多個規則同時要求同一身份時按上限合併，並在身份面板與規則參考中提示
- FS 多副規則會以提醒方式處理，導出/開始遊戲時若確認會自動寫入特殊規則
- **特殊規則分兩欄**：劇本編輯自由，違反標準規則的內容寫入「僅劇作家」特殊規則；
  「主人公可見」特殊規則專門寫給主人公看（公開卡與遊戲資料板只顯示這部分）
- 規則細則依《防村指南》Q&A 同步：十周年規則下每輪限1次的能力被拒絕後不視為已使用
  （WM 劇本依特規視為已使用）；轉校生登場前不參與輪迴開始效果；模仿犯公開的是
  同身份的角色名而非身份本身；角色池收起後主體完全隱藏
- 匯出/匯入 JSON，或直接開始遊戲

## 2. 遊戲（game.html）

實現 FS + BTX 兩個模組的完整規則引擎：

- 四塊版圖（醫院/神社/都市/學校）與資料板（天數、輪迴、預定事件）
- 行動牌：劇作家 3 張、主人公 1 張（含 2/3 人規則的牌組輪換）
- 卡牌結算順序、移動合成、禁止牌優先、邪教徒/時間旅者特例
- 劇作家能力階段（主謀、傳謠人、流言四起等）
- 友好能力階段（含無視友好/必定無視友好/不可拒絕）
- 事件結算（含醫院事故附加條件、蝴蝶效應）
- 夜間能力（殺人狂、殺手、求愛者、時間旅者）
- 輪迴結束失敗條件判定、輪迴重置、最終決戰（BTX）
- 劇作家秘密視圖切換（身份、當事人、規則）

## 2.5 本地模擬對戰（AI 劇作家）

- 在遊戲設定畫面選擇「🎮 本地模擬對戰（AI 劇作家）」，玩家操控全部 3 名主人公，
  AI 自動扮演劇作家（打牌、能力階段、拒絕、夜間能力、移動方向都由 AI 決定）
- AI 會依規則 Y/X 推導勝利目標（關鍵人物、版圖密謀、殺人狂、妄想病毒、戀愛風景線等），
  部分劇本有預設策略，並會隨玩家行為（例如關鍵人物密謀一直被壓制）動態切換主/次目標
- AI 會「藏身份」：拒絕友好、夜間殺戮、邪教徒取消、戀人連動等高暴露行動會依
  是否有最終決戰（BTX）與已暴露次數權衡，避免讓主人公在最終決戰更好猜
- 每一輪輪迴會變換主路徑與誘餌目標、調整拒絕與移動方式，防止主人公靠同一套邏輯累積資訊
- 「⚙ 設定」內可調整 **AI 難度**（簡單 / 普通 / 困難），影響 AI 抉擇的隨機性
- 對局中 AI 的行動會以卡牌翻開、棋子移動與事件記錄呈現，亦可沿用結算動畫設定

## 3. 多人聯機（multiplayer.html）

- 一個房間最多 4 名玩家（最少 1 名，可單人獨占全部英雄用於調試/驗證劇本）
- 4 個可操控英雄：劇作家 + 主人公 A/B/C（對應懷表/書/App/群像 Logo）
- 由**房主**分配英雄：劇作家與主人公不可同人；一名玩家可持有多名主人公（不足 4 人時）
- 每位玩家隨機分配頭像（可重擲）
- 持有多名英雄的玩家可在右上角切換視角；各視角互相獨立，看不到其他視角的蓋牌，但能看到自己的
- 右側對話欄隨時互動
- 伺服器為權威端（Node 引擎），每個玩家只收到自己可見的狀態（主人公看不到劇作家的牌與秘密、劇作家看不到主人公的牌）

## 4. 多語言（設定中切換）

- 支援 **繁體中文 / 简体中文 / 日本語 / English**，可在每個頁面右上角的語言下拉框中切換，也會持久化到瀏覽器
- 遊戲進行中可從「⚙ 設定」面板切換語言，立即生效（含結算動畫開關與速度設定）
- 術語翻譯以 Fandom《術語對照表 / 語言參照表 / Language reference》為準：
  角色名、身份名、規則Y/X、事件、版圖、行動牌、模組名與基本用語（友好/不安/密謀等）
- 界面文字、劇本編輯器驗證訊息、事件記錄（結算/移動/能力/事件/輪迴/最終決戰）與多人聯機界面同步翻譯
- 未收錄於術語表的長文（如角色卡上的能力說明）暫維持繁體中文原文，術語名稱仍會隨語言切換

## 5. 界面風格

- 採用 **WinUI 3 / Fluent 扁平風格（深色）**：中性底色、單一強調色（亮藍）、無漸變與輝光、
  Segoe UI 字體、4/8px 圓角
- 舊版「輪迴之夜」深紫金主題備份於 `css/style.dark-theme.backup.css`，若要還原將它覆蓋回
  `css/style.css` 即可

## 啟動方式

雙擊 `game\start.bat`（或 `game\start.ps1`），會自動啟動**多人伺服器**（Node，
`http://localhost:8360`）並開啟瀏覽器；若找不到 Node.js 則退回純靜態伺服器
（`http://localhost:8357`，單人可用、多人需 Node）。

多人伺服器啟動器有兩份：專案根目錄 `D:\Rooper\start_server.bat` 與
`game\start_server.bat`，內容相同。

也可直接執行命令：

```bash
node server/multiplayer.js        # 預設 http://localhost:8360
```

然後開啟 `http://localhost:8360` 進入大廳（可建立/加入房間）。手機/平板亦可直接
用同一區網 IP（例如 `http://192.168.x.x:8360`）開啟；界面已針對小螢幕適配。

## 自動化測試

```bash
node tests/engine_test.js    # 引擎規則測試（移動合成/禁止優先/能力/輪迴/最終決戰）
node tests/ui_e2e_test.js    # 端到端 UI 測試（Playwright + Edge）
node tests/i18n_e2e_test.js  # 多語言端到端測試（四頁面語言切換與持久化）
node tests/ai_e2e_test.js    # AI 劇作家本地對戰測試（自動打牌與推進）
node tests/presets_e2e_test.js # 預設劇本選擇頁測試（列表/搜尋/模式/AI 啟動）
node tests/multiplayer_test.js        # 多人聯機整合測試（3 客戶端、隱私過濾、提示路由、聊天）
node tests/multiplayer_e2e_test.js    # 多人聯機瀏覽器測試（雙頁面、視角切換）
```

測試需要 Node.js 與 Playwright；`ui_e2e_test.js` 會自動使用本機
Microsoft Edge 執行無頭測試。
